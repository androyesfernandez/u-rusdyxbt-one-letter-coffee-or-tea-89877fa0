A tiny entry for [u-rusdyxbt-one-letter-coffee-or-tea-89877fa0](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0)
on make.fun: a program that writes exactly one letter — `A`, standing
for coffee — into `/output/entry.txt`, and nothing else.

Run it with Python 3.13 and no network:

```sh
python3 main.py
```

The letter it writes is the whole entry: one character, no newline,
no punctuation. Behind it sits a 20-trial duel test against `B` (tea),
judged on the kit brief's criteria in order — vivid, then funny, then
true — which coffee won 16–4 (total margins 43–6): coffee reads as the
more vivid answer, dark roast and steam and the morning jolt, and the
funnier and truer one more often than not.
